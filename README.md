# 同盟战功统计看板 · 九天揽月楼

一个纯前端的同盟战功统计看板：每天导入游戏导出的 CSV 战报，自动计算当日增量、周度累计、全盟排行、门阀对比、人员变动与活跃度。

## 在线使用

**https://xwh77.github.io/alliance-board/**

打开上面的地址即可。首次打开自带演示数据；点「导入战报」选择 CSV，导入第一份真实战报后演示数据会自动清空。

## CSV 表头

```
成员,门阀,州,势力值,战功本周,贡献本周,助攻本周,捐献本周
```

至少需要「成员」以及「战功本周 / 贡献本周 / 助攻本周」中的一列。文件名带日期（如 `战报_2026-11-10.csv`）会自动识别。

## 数据说明

- 数据只保存在当前浏览器的 localStorage，不上传服务器。
- 清理浏览器数据会丢数据，请在「管理中心 → 备份与数据」中导出 JSON 备份。
- 当日增量 = 今日本周累计 − 昨日本周累计；首次导入无基线，会标注「本周至今 · 无基线」；周一自动识别新周。
- 活跃度 = 战功 50% + 贡献 30% + 助攻 20%（可在管理中心调整）。

## 本地运行

下载 `index.html` 直接用浏览器打开即可；单文件、离线可用。

本项目参考「同盟战功统计看板」的界面与数据口径制作，未包含参考站的「招贤纳士」「铁匠铺」等独立小游戏。
